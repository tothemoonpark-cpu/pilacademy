### 4-3. `watch_runner.py`만 쓰는 최소 설치 절차 (Windows)

숨고 쪽(`soomgo_watch.py`·Playwright·로그인)은 **설치하지 않습니다.** pip 설치도 필요 없습니다(표준 라이브러리만 사용, Python 3.10 이상).

1. **폴더를 따로 만들기.** 기존 숨고 도구 폴더와 섞지 않습니다. 저장소의 `tools/local_watch`를 통째로 받아 `C:\local_watch`처럼 새 경로에 둡니다. 실제로 쓰는 파일은 `watch_runner.py`·`notify.py`·`dedupe.py`·`config\`뿐이고, 나머지 파일은 실행하지 않으면 영향이 없습니다.
2. **파이썬 확인.** `python --version`(3.10 이상). `where python`으로 전체 경로를 메모해 둡니다.
3. **설정 복사.**
   ```bat
   cd C:\local_watch
   copy config\watch.example.json config\watch.json
   copy config\notify.example.json config\notify.json
   ```
4. **`config\watch.json` 수정.** `workdir`를 감시할 스크립트가 있는 폴더(예: 칼럼 폴더)로, `jobs`를 실제로 돌릴 명령(예: `["python","도구\\전수점검.py"]`)과 `interval_minutes`로 고칩니다. 예시 파일의 `도구/전수점검.py`·`도구/세트감시.py`가 노트북에 실제로 있는지는 이 보고서가 확인하지 못했습니다.
5. **알림 채널 정하기(`config\notify.json`).** ntfy를 쓰면 `topic`을 추측 불가능한 긴 이름으로 바꾸고 휴대폰 ntfy 앱에서 같은 토픽을 구독합니다. 쓰지 않으려면 ntfy·텔레그램을 `enabled:false`로 두면 Windows 토스트로 대체됩니다(토스트용 `win10toast` 또는 `plyer`가 없으면 콘솔 출력만 됩니다). 점검: `python notify.py "테스트" "도착하나요" alert`
6. **수동 1회 시험(등록 전).** `python watch_runner.py --config config\watch.json --force` — 모든 작업이 즉시 실행되고, 경보 패턴이 있으면 알림이 옵니다. 같은 명령을 다시 돌려 「새 경보 0줄」이 나오면 중복 억제가 정상입니다.
7. **작업 스케줄러 등록(이름을 기존과 다르게).**
   ```bat
   schtasks /Create /TN "local_watch\runner" /SC MINUTE /MO 10 /TR "pythonw C:\local_watch\watch_runner.py" /F
   ```
   `soomgo` 작업은 **만들지 않습니다.** `pythonw`는 오류가 안 보이니 6단계를 먼저 통과시킨 뒤 등록하세요. 확인은 `schtasks /Query /TN "local_watch\runner" /V /FO LIST`, 제거는 `schtasks /Delete /TN "local_watch\runner" /F`.
8. **알아둘 점.** 노트북이 절전이면 돌지 않습니다. 각 작업은 `interval_minutes`가 지난 뒤 다음 10분 틱에서 실행됩니다(주기 오차 최대 10분). 알림 본문에 감시 명령의 출력 줄이 그대로 들어가므로 개인정보가 출력되는 명령은 연결하지 마세요.
