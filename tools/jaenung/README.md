# 재능넷 보류 재능 14개 보완 자료

재능넷 심사에서 보류된 재능 14개를 사유 4가지에 맞춰 고친 자료입니다. 사이트 HTML은 바꾸지 않았습니다.

## 폴더 구성

| 경로 | 내용 | 개수 |
|---|---|---|
| `상세설명/01.md`~`14.md` | 재능별 상세 설명(한국어 경어체) | 14 |
| `이미지/01.png`~`14.png` | 대표 이미지 1000×750, 글자와 단순 도형만 | 14 |
| `점검표.md` | 14개 × 사유 4가지 대조표 | 1 |
| `make_images.py` | 이미지 생성 스크립트 | 1 |
| `fonts/` | Noto Sans KR(가변 폰트)와 OFL 라이선스 | 2 |

## 14개와 파일 번호

1 보고서·제안서·소개서 작성 / 2 영어·중국어 번역 / 3 공무원 직무수행계획서 / 4 NCS 자기소개서 / 5 대기업 자기소개서 / 6 경력직 이력서 / 7 면접 질문 100 / 8 정부지원사업 사업계획서 / 9 보고서·기획서 한 장 / 10 PPT 한 장 한 메시지 / 11 상세페이지 문구 / 12 AI 프롬프트 120 / 13 맞춤법 150 / 14 보도자료

## 먼저 채울 자리

상세설명 파일 안의 중괄호 자리를 전부 채웁니다.

| 자리 | 넣을 것 |
|---|---|
| `{{가격}}` | 기본 가격 |
| `{{기간}}` | 작업 기간 또는 파일 전달 기한 |
| `{{쪽수}}` | 전자책 최종 쪽수(전자책 12개) |
| `{{옵션 가격}}` | 옵션별 추가 비용 |
| `{{사실 확인 후 기입}}` 등 | 실제 이력과 건수. 확인되는 것만 |
| `예시 1: ___`, `예시 2: ___` | 실제 작업 캡처와 한 줄 설명 |

## 재능넷에 올리는 순서

1. 재능넷에 로그인해 **등록한 재능 관리**로 들어갑니다.
2. 보류된 재능 14개 중 하나를 골라 **재능 수정하기**를 누릅니다.
3. 대표 이미지를 `이미지/NN.png`로 바꿉니다(같은 번호의 재능).
4. 상세 설명 입력칸의 기존 내용을 지우고 `상세설명/NN.md`의 내용을 붙여 넣습니다. 표는 재능넷 편집기에서 깨지면 목록 형식으로 풀어 씁니다.
5. 가격, 작업 기간, 수정 횟수(기본 2회), 옵션 칸을 상세 설명의 수치와 똑같이 입력합니다.
6. 상세 설명의 「작업 예시」 자리에 실제 캡처 이미지를 넣습니다. 전자책은 미리보기 이미지(목차, 본문 일부)를 함께 넣습니다.
7. 저장 후 **승인 재요청**을 누릅니다.
8. 14개를 모두 마칠 때까지 1~7을 반복합니다. 마친 재능은 아래 표에 표시합니다.

| 번호 | 재능 수정 | 이미지 교체 | 예시 캡처 | 승인 재요청 |
|---|---|---|---|---|
| 01~14 | ☐ | ☐ | ☐ | ☐ |

진행 상황은 14개 모두 같은 4칸을 확인합니다(14 × 4 = 56칸).

## 이미지 다시 만들기

```
python3 make_images.py
```

Pillow가 필요하며, 한글 폰트는 `fonts/NotoSansKR-VF.ttf`(SIL Open Font License 1.1)를 씁니다. 글귀를 고치려면 `make_images.py`의 해당 함수(`i01`~`i14`)를 수정합니다.

## 주의

- 승인은 한 번에 한 개씩 요청하고, 같은 문구·같은 이미지를 다른 재능에 복사하지 않습니다. 보류 사유 ①과 ④가 그 때문입니다.
- 상세 설명에 적은 경력은 사실만 남깁니다. 확인되지 않는 항목은 문단째 지워도 구조가 깨지지 않습니다.
