# 사실검수_API.py

반려동물 SNS 세트 `posts.json`(글 9편, 각 x·threads·ig 본문)의 **숫자·연구 인용·의학 사실**을 API로 대조해 마크다운 표로 저장하는 도구입니다. 사이트 HTML은 건드리지 않습니다.

## 사용법

```bash
pip install anthropic                      # --dry 만 쓸 때는 불필요
export ANTHROPIC_API_KEY=sk-ant-...        # 모델: claude-sonnet-5-5
export NCBI_EMAIL=you@example.com          # 선택. PubMed 요청에 연락처로 첨부

python3 tools/사실검수_API.py tools/예시_posts.json              # → tools/예시_posts_사실검수.md
python3 tools/사실검수_API.py posts.json -o 결과/검수.md          # 출력 경로 지정
python3 tools/사실검수_API.py tools/예시_posts.json --dry         # 네트워크·API 없이 구조 시험
```

종료코드: 모든 글 성공 0, 하나라도 끝내 실패하면 1.

### 입력 형식
`{"posts": [...]}` 또는 최상위 배열. 글마다 `no`(또는 `id`, 없으면 순번), `title`(선택), `x`·`threads`·`ig`(문자열 또는 문자열 배열). 예시는 `tools/예시_posts.json`.

### 출력
`글 | 플랫폼 | 주장 문장 | 검증 결과 | 근거 PMID/출처 | 메모` 표와 위쪽 요약. 검증 결과는 **확인 / 불일치 / 근거 없음**이며, 글 전체가 두 번 다 실패하면 `미판정(오류)` 한 행이 들어갑니다.

## 동작
1. 글 1편씩 처리(글 단위로 나눔). 시도 1회의 시간 예산은 **170초**이고, 남은 시간이 부족하면 해당 시도를 중단합니다.
2. Claude가 본문에서 검증 대상 주장(숫자·연구·의학)을 구조화 JSON으로 추출하고, 연구·의학 주장에는 PubMed 검색어를 붙입니다.
3. PubMed E-utilities `esearch`→`efetch`(키 불필요, 요청 간 0.4초 간격)로 주장당 최대 3편의 PMID·제목·연도·초록을 가져옵니다.
4. Claude가 초록과 대조해 판정합니다. 초록에 없는 내용은 확인하지 않습니다.
5. 실패한 글은 **1회 재시도**합니다.

## 한계
- **판정은 보조 자료입니다.** 모델 판단이 틀릴 수 있어, 특히 `확인`·`불일치` 모두 PMID 초록을 사람이 한 번 열어 보는 것을 전제로 합니다.
- PubMed 검색어는 모델이 만든 것이라 맞는 논문이 안 잡히면 `근거 없음`이 나옵니다. 이는 "거짓"이 아니라 "이 도구가 근거를 못 찾음"입니다.
- 대조 대상은 **초록**뿐입니다. 본문 표·수치, 초록에 없는 세부는 확인할 수 없습니다. PubMed에 없는 한국 통계·가이드라인·단행본은 자동으로 대조되지 않습니다(숫자 주장은 PubMed를 조회하지 않고, 모델 판단과 공인 출처명에 의존).
- 한국어 문장을 영어 검색어로 바꾸는 과정에서 손실이 생길 수 있습니다.
- 170초 예산은 글 1편·시도 1회 기준입니다. 재시도까지 하면 글당 최악 약 340초이며 전체 소요는 글 수에 비례합니다. 주장이 매우 많은 글은 예산 초과로 실패할 수 있습니다.
- `--dry`는 숫자·"연구" 키워드가 든 문장을 뽑아 모두 `근거 없음`으로 채우는 구조 시험용이며 판정은 무의미합니다.
- PubMed 장애 시 해당 주장은 근거 없이 판정됩니다(메모에 오류 표시).
- 이 환경에서는 Anthropic API 키가 없어 실제 모델 호출은 시험하지 못했고, PubMed 실호출과 Claude 호출부(모의 객체) 경로만 검증했습니다.
