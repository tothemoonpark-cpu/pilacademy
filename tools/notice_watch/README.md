# notice_watch — 강사·교육과정 공고 감시기 (AI 없음)

표준 라이브러리만 쓰는 파이썬 스크립트입니다. 소스 페이지의 링크 제목에서 키워드를 찾아, **이전에 못 본 항목만** `_notice_watch_새공고.md` 맨 위에 적고 윈도우 토스트로 알립니다.

## 사용
1. `python notice_watch.py` 로 한 번 실행 — 첫 실행은 소스별 기준선만 저장합니다(알림 없음).
2. `register_windows.bat` 실행 — 작업 스케줄러에 매일 09:30 등록.
3. 결과 `_notice_watch_새공고.md`, 상태 `state.json` 은 이 폴더에 생깁니다. 상태를 지우면 다시 기준선부터 시작합니다.

## 설정 (`config/sources.json`)
- `설정`: 타임아웃(15초), 전체 제한(100초), 공통키워드, `계절_적용`(기본 false = 항상 확인; true 면 소스의 `"계절": [월,...]` 적용), `첫실행_알림`, `토스트`.
- `소스`: `url` 이 `null` 인 곳은 목록 주소를 아직 못 찾은 것입니다(`메모` 참고). 주소를 넣으면 바로 감시됩니다. `추가키워드`로 소스별 키워드 추가, `"사용": false` 로 끌 수 있습니다.
- 부산교육청처럼 POST 검색이 필요한 곳은 `방식`·`검색파라미터`·`검색어`·`폼`을 씁니다(파라미터는 추정값, 실패하면 GET 목록으로 대체).
- 접속 실패 소스는 건너뛰고 결과에 `확인 실패: 이름` 으로 남습니다.
