- **대상**: git 추적 중인 텍스트 파일 전부(html, llms.txt, search-index.json, sitemap.xml, stats.js 등) 약 470개. 이미지·영상은 제외했습니다.
- **찾은 표기**: 경력 = 스무 해(가까이/동안/가까운), 20년(가까이), 약 20년, 십수 년, 이십 년 등. 인원 = 550명, 414명, 전교생 N명, 학년별.
- **줄 번호**: 파일의 실제 줄 번호입니다. `search-index.json`은 파일 전체가 1줄이라 `1 (u=페이지)`처럼 **항목의 `u` 값**으로 표시했습니다. 접두어 `[JSON-LD]`·`[title]`은 구조화 데이터·제목 줄, 메타 태그와 `alt`·`title` 속성의 문구는 태그를 벗기고 속성값을 읽어 옮겼습니다.
- **같은지 표시**: ✅ 정본과 같음 / ⚠️ 변형(같은 계열이지만 글자가 다름) / ❌ 정본과 다름 / ➖ 비교 대상 아님(정본에 없는 수치, 정본 자체의 규칙 문장) / 해당 없음(경력 서술이 아님).
- 한 줄에 같은 표기가 여러 번 나오면 한 행으로 묶었습니다. 다른 표기가 섞여 있으면 행을 나눴습니다.

- 정규식 검색이라 「이십 년」 같은 한글 숫자 표기는 찾았으나 결과가 없었고, 「19년」 등 다른 숫자의 경력 표기는 llms.txt·index.html·author.html에서 확인했을 때 나오지 않았습니다. 그 밖의 파일은 같은 방식으로 전수 확인하지 않았습니다.
